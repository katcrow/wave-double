# 돌파3%기법

매집 후 고점 돌파 + RSI 돌파 필터를 결합한 단기 매매 전략.
종가(고가)로 최근 N일 신고가를 돌파하되, 오늘 거래량이 최근 W일 중 최대가 아니라는 점(이미 매집 완료)을 활용하고,
RSI가 약세 영역에서 기준선을 상향 돌파하는 구간에서만 진입한다.

> 이 문서는 향후 PRD 작성 및 "또는(OR)" 다중 후보 전략 결합 검색을 위한 기초 자료이다.
> 각 후보 조합은 별도로 기술하며, 공통 진입 조건은 하단의 "공통 구조"를 우선한다.

---

## 1. 공통 구조 (Core Concept)

### 진입 조건 (모두 동시 충족 — AND)
1. **고점 돌파**: 고가(또는 종가)가 최근 `N`일 신고가를 돌파
2. **매집 확인**: 오늘 거래량 / 최근 `W`일 중 최대 거래량 비율 < `VMR` (거래량 없이 돌파 = 매도세 부재)
3. **장기 하단 반전**: 현재가 < `MA_long` (장기 이평선 하단에서의 반전)
4. **RSI 돌파**: `RSI(period, smooth)` 가 어제 `RSI_thr` 미만 → 오늘 `RSI_thr` 이상 (상향 돌파) + `RSI >= RSI_min`

### 청산 조건
- **익절(TP)**: +3% (고정)
- **손절(SL)**: -5% (기본)
- **최대 보유**: 20일

---

## 2. 핵심 후보 조합 (OR 검색용)

다음 후보들은 서로 다른 파라미터로, 최종 전략에서는 **"또는(OR)"** 으로 결합하여 검색한다.
각 후보는 승률/월간 거래건수(월 거래량) 사이의 트레이드오프를 가지며, 목표 승률 70% 이상, 실전 운용 가능한 월간 건수를 고려해야 한다.

### 후보 A — 최고 승률 (희소 선별형)
| 항목 | 값 |
|------|-----|
| 고점 기간 (N) | 20 |
| 거래량 윈도우 (W) | 3 |
| 거래량 비율 (VMR) | 0.95 |
| 장기 이평선 (MA_long) | 240 |
| RSI 파라미터 | period=10, smooth=6 |
| RSI 돌파 기준 (RSI_thr) | 42 |
| RSI 최소 (RSI_min) | 30 |
| 익절 (TP) | 3% |
| 손절 (SL) | 5% |
| 최대 보유 | 20일 |
| **승률** | **83.1%** |
| 평균 수익 | +1.93% |
| 총 거래 | 77건 |
| **월간 거래건수** | **1.1건** |

- 특징: 승률이 가장 높고 종목 그룹 무관 안정적(93% 그룹이 70%↑). 다만 거래 빈도가 낮음.

### 후보 B — 표본 확대형 (월간 건수 확보)

| RSI 최소 (RSI_min) | 30 |
| 익절 (TP) | 3% |

- 특징: 승률 77% 이상 유지하면서 월간 건수를 3배 확보. 표본이 많아 통계적 신뢰도 상대적으로 높음.

## 3. 청산 조건별 성능 요약 (RSI42, h20, w3 기준)

익절(TP)와 손절(SL)에 따른 승률/수익 변화 (거래건수는 진입조건이 같아 고정 77건):

| TP | SL | 승률 | 평균수익 |
|----|----|------|----------|
| 3% | 3% | 66.2% | +1.217% |
| **3%** | **5%** | **83.1%** | **+1.932%** |
| 3% | 7% | 84.4% | +1.760% |
| 3% | 10% | 87.0% | +1.856% |
| 5% | 5% | 62.3% | +1.521% |
| 7% | 5% | 54.5% | +1.496% |
| 10% | 5% | 46.8% | +1.546% |

**핵심 인사이트:**
- **TP 확대는 승률을 급락**시킴 (이 전략의 상승 모멘텀이 짧아 +3% 익절이 최적)
- **SL 확대(5→10%)는 승률을 상승**시킴
- TP3%/SL3% 동일 케이스는 승률 66%로 목표 70% 미달 → 권장하지 않음

## 4. 파라미터 의미

| 파라미터 | 의미 |
|----------|------|
| `N` (고점 기간) | 최근 N일 중 최고가를 돌파해야 함. 클수록 신호 희소 |
| `W` (거래량 윈도우) | 최근 W일 중 최대 거래량보다 오늘 거래량이 작아야 함 (매집 완료 확인) |
| `VMR` (거래량 비율) | 오늘 거래량 / W일 최대 거래량 < VMR |
| `MA_long` (장기 이평선) | 현재가가 이 이평선 아래일 때만 진입 (장기 하단 반전) |
| `RSI(period, smooth)` | RSI 기간/평활 파라미터 (최적: 10, 6) |
| `RSI_thr` (돌파 기준) | RSI가 이 값을 상향 돌파할 때 (최적: 42, 40~45 범위에서 안정) |
| `TP` / `SL` | 익절 / 손절 비율 (최적: TP3% / SL5~10%) |

---

## 5. 향후 계획 (PRD 전 단계)

1. 위 후보 A/B/C를 **"또는(OR)"** 조건으로 결합하여 검색
   - A → B → C 순으로 조건을 OR 확장하면 월간 거래건수는 늘고 승률은 소폭 하락
2. 각 후보에 대한 **OOS(워크포워드) 검증** 실시 (과적합 확인)
3. 후보별 승률/월간 건수 트레이드오프를 기준으로 PRD 작성
