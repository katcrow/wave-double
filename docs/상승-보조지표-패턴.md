### 1. 추세 추종 지표 (Trend Indicators)

#### 단순이동평균 (Simple Moving Average, SMA)
*   **정의:** 일정 기간 동안의 가격을 산술 평균하여 추세의 방향성을 매끄럽게 보여주는 가장 기본적인 지표입니다.
*   **수학적 공식:** 
    \\[SMA_t = \frac{\sum_{i=0}^{n-1} Close_{t-i}}{n}\\]
*   **프로그래밍 매수 조건 (골든 크로스):**
    ```python
    import pandas as pd

    # n1: 단기(예: 50), n2: 장기(예: 200)
    df['SMA_short'] = df['close'].rolling(window=50).mean()
    df['SMA_long'] = df['close'].rolling(window=200).mean()

    # 단기 이평선이 장기 이평선을 하단에서 상단으로 돌파할 때
    df['buy_signal'] = (df['SMA_short'].shift(1) <= df['SMA_long'].shift(1)) & (df['SMA_short'] > df['SMA_long'])
    ```

#### 지수이동평균 (Exponential Moving Average, EMA)
*   **정의:** 최근 가격에 더 높은 가중치를 부여하여 가격 변동에 민감하게 반응하고 지연 시간을 줄인 이동평균입니다.
*   **수학적 공식:** 
    \\[EMA_t = (Close_t \times \alpha) + (EMA_{t-1} \times (1 - \alpha)) \quad \left(\alpha = \frac{2}{n + 1}\right)\\]
*   **프로그래밍 매수 조건 (가격 상향 돌파):**
    ```python
    df['EMA_20'] = df['close'].ewm(span=20, adjust=False).mean()

    # 종가가 20일 EMA를 상향 돌파할 때
    df['buy_signal'] = (df['close'].shift(1) <= df['EMA_20'].shift(1)) & (df['close'] > df['EMA_20'])
    ```

#### 이중지수이동평균 (Double Exponential Moving Average, DEMA)
*   **정의:** EMA를 이중으로 평활화하여 이동평균의 고유한 한계인 지연 시간(Lag)을 획기적으로 줄인 지표입니다.
*   **수학적 공식:** 
    \\[DEMA_t = 2 \times EMA_t - EMA(EMA_t)\\]
*   **프로그래밍 매수 조건 (DEMA 우상향 전환):**
    ```python
    ema1 = df['close'].ewm(span=20, adjust=False).mean()
    ema2 = ema1.ewm(span=20, adjust=False).mean()
    df['DEMA'] = 2 * ema1 - ema2

    # DEMA가 하락세를 멈추고 우상향으로 꺾이는 변곡점 포착
    df['buy_signal'] = (df['DEMA'].shift(2) >= df['DEMA'].shift(1)) & (df['DEMA'].shift(1) < df['DEMA'])
    ```

#### 허일 이동평균 (Hull Moving Average, HMA)
*   **정의:** 가중이동평균(WMA)을 기반으로 평활화를 유지하면서도 지연을 거의 완벽히 제거하여 빠른 추세 전환을 보여주는 평균선입니다.
*   **수학적 공식:** 
    \\[HMA = WMA\left(2 \times WMA\left(\frac{n}{2}\right) - WMA(n), \sqrt{n}\right)\\]
*   **프로그래밍 매수 조건 (기울기 양수 전환):**
    ```python
    import numpy as np

    def wma(series, period):
        weights = np.arange(1, period + 1)
        return series.rolling(period).apply(lambda x: np.dot(x, weights) / weights.sum(), raw=True)

    n = 9
    half_length = int(n / 2)
    sqrt_length = int(np.sqrt(n))

    raw_hma = 2 * wma(df['close'], half_length) - wma(df['close'], n)
    df['HMA'] = wma(raw_hma, sqrt_length)

    # HMA 선의 기울기가 우상향으로 전환될 때
    df['buy_signal'] = (df['HMA'].shift(1) < df['HMA']) & (df['HMA'].shift(2) >= df['HMA'].shift(1))
    ```

#### MACD (Moving Average Convergence Divergence)
*   **정의:** 장단기 지수이동평균선의 수렴과 발산을 통해 추세의 강도, 방향, 모멘텀을 측정하는 대표적인 지표입니다.
*   **수학적 공식:** 
    \\[MACD\_Line = EMA_{12}(Close) - EMA_{26}(Close)\\]
    \\[Signal\_Line = EMA_{9}(MACD\_Line)\\]
    \\[Histogram = MACD\_Line - Signal\_Line\\]
*   **프로그래밍 매수 조건 (시그널 교차 및 0선 돌파):**
    ```python
    ema12 = df['close'].ewm(span=12, adjust=False).mean()
    ema26 = df['close'].ewm(span=26, adjust=False).mean()
    df['MACD_line'] = ema12 - ema26
    df['Signal_line'] = df['MACD_line'].ewm(span=9, adjust=False).mean()

    # 1. MACD 선이 시그널 선을 상향 교차 (골든 크로스)
    cond1 = (df['MACD_line'].shift(1) <= df['Signal_line'].shift(1)) & (df['MACD_line'] > df['Signal_line'])
    # 2. MACD 선이 0선 위로 올라갈 때 (단기 강세 확증)
    cond2 = df['MACD_line'] > 0

    df['buy_signal'] = cond1 & cond2
    ```

#### ADX & DMI (Average Directional Index)
*   **정의:** 시장의 상승 및 하락 강도를 각각 지수화하고(+DI, -DI), 방향과 관계없이 현재 추세의 절대 강도(ADX)를 정량화합니다.
*   **수학적 공식:** 
    \\[+DM = High_t - High_{t-1} \quad (if > 0 \text{ and } > -DM)\\]
    \\[-DM = Low_{t-1} - Low_t \quad (if > 0 \text{ and } > +DM)\\]
    \\[+DI = 100 \times \frac{EMA(+DM)}{ATR}, \quad -DI = 100 \times \frac{EMA(-DM)}{ATR}\\]
    \\[DX = 100 \times \frac{|+DI - -DI|}{+DI + -DI}, \quad ADX = EMA(DX)\\]
*   **프로그래밍 매수 조건 (방향성 교차 및 추세 가속):**
    ```python
    # 실무적으로는 TA-Lib 라이브러리를 사용하거나 아래 연산식을 사용합니다.
    # (+DI가 -DI를 상향 돌파하고, 추세 강도지수 ADX가 20 이상으로 상승하기 시작할 때)
    df['buy_signal'] = (df['plus_di'].shift(1) <= df['minus_di'].shift(1)) & \
                       (df['plus_di'] > df['minus_di']) & \
                       (df['ADX'] >= 20)
    ```

#### 일목균형표 (Ichimoku Cloud)
*   **정의:** 전환선, 기준선, 후행스팬 및 두 선행스팬이 만드는 구름대를 활용하여 시장의 저항, 지지 및 추세 균형을 종합 진단합니다.
*   **수학적 공식:** 
    \\[Tenkan(전환선) = \frac{Max(High, 9) + Min(Low, 9)}{2}\\]
    \\[Kijun(기준선) = \frac{Max(High, 26) + Min(Low, 26)}{2}\\]
    \\[Senkou\_A(선행스팬A) = \frac{Tenkan + Kijun}{2} \quad (26\text{봉 선행 시각화})\\]
    \\[Senkou\_B(선행스팬B) = \frac{Max(High, 52) + Min(Low, 52)}{2} \quad (26\text{봉 선행 시각화})\\]
    \\[Chikou(후행스팬) = Close_t \quad (26\text{봉 후행 시각화})\\]
*   **프로그래밍 매수 조건 (삼역호전 - 강세 전환):**
    ```python
    # 1. 전환선이 기준선을 상향 돌파
    cond1 = 전환선 > 기준선
    # 2. 주가가 구름대(선행스팬 A, B 중 최고값) 위에 위치
    cond2 = df['close'] > df[['Senkou_A', 'Senkou_B']].max(axis=1)
    # 3. 후행스팬이 26일 전의 주가를 상향 돌파
    cond3 = df['close'] > df['close'].shift(26)

    df['buy_signal'] = cond1 & cond2 & cond3
    ```

#### 아룬 오실레이터 (Aroon Oscillator)
*   **정의:** 최근 특정 기간 내에 최고가와 최저가가 도달한 시점을 역산하여 시장이 상승 및 하락 중 어느 방향으로 치우쳐 있는지 진단합니다.
*   **수학적 공식:** 
    \\[Aroon\_Up = \frac{n - \text{최고가 이후 경과일수}}{n} \times 100\\]
    \\[Aroon\_Down = \frac{n - \text{최저가 이후 경과일수}}{n} \times 100\\]
    \\[Aroon\_Oscillator = Aroon\_Up - Aroon\_Down\\]
*   **프로그래밍 매수 조건 (0선 상향 돌파):**
    ```python
    # Aroon Up이 Aroon Down을 뛰어넘어 오실레이터가 플러스로 진입할 때
    df['buy_signal'] = (df['Aroon_Oscillator'].shift(1) <= 0) & (df['Aroon_Oscillator'] > 0)
    ```

#### 슈퍼트렌드 (SuperTrend)
*   **정의:** 가격 변동폭(ATR)을 활용하여 추세 지지/저항선을 도출하고, 추세 변화 시 색상과 위치가 동적으로 바뀌는 지표입니다.
*   **수학적 공식:** 
    \\[Basic\_Upper\_Band = \frac{High + Low}{2} + (Multiplier \times ATR(n))\\]
    \\[Basic\_Lower\_Band = \frac{High + Low}{2} - (Multiplier \times ATR(n))\\]
*   **프로그래밍 매수 조건 (상승 반전):**
    ```python
    # 주가가 슈퍼트렌드 상단 밴드(하락 저항선)를 돌파하며 하단 지지선(초록색)으로 전환될 때
    df['buy_signal'] = (df['close'].shift(1) <= df['SuperTrend'].shift(1)) & (df['close'] > df['SuperTrend'])
    ```

#### 파라볼릭 SAR (Parabolic Stop and Reverse)
*   **정의:** 시간 경과에 따라 가속인수(AF)를 누적 적용하여 가격 추세의 한계와 정지 및 반전 시점을 점으로 제시하는 추종 지표입니다.
*   **수학적 공식:** 
    \\[SAR_{t+1} = SAR_t + AF \times (EP - SAR_t)\\]
*   **프로그래밍 매수 조건 (점의 위치 반전):**
    ```python
    # 점이 가격 위(하락)에 있다가 가격 아래(상승)로 처음 찍히기 시작할 때
    df['buy_signal'] = (df['close'].shift(1) <= df['SAR'].shift(1)) & (df['close'] > df['SAR'])
    ```

### 2. 모멘텀 오실레이터 지표 (Momentum Oscillators)

#### RSI (Relative Strength Index)
*   **정의:** 일정 기간 동안 가격의 평균 상승폭과 평균 하락폭을 비교해 시장 매수 강도의 과열 및 침체를 0~100 사이로 환산합니다.
*   **수학적 공식:** 
    \\[RSI = 100 - \frac{100}{1 + RS} \quad \left(RS = \frac{\text{평균 상승폭}}{\text{평균 하락폭}}\right)\\]
*   **프로그래밍 매수 조건 (과매도 탈출 및 50 돌파):**
    ```python
    # 1. 과매도 기준선(30) 이하에서 탈출하여 반등할 때
    df['buy_signal_oversold'] = (df['RSI'].shift(1) <= 30) & (df['RSI'] > 30)

    # 2. 혹은 추세 중심선인 50선을 강력하게 돌파할 때
    df['buy_signal_center'] = (df['RSI'].shift(1) <= 50) & (df['RSI'] > 50)
    ```

#### 스토캐스틱 오실레이터 (Stochastic Oscillator)
*   **정의:** 최근 일정 기간의 변동 범위 내에서 현재 종가가 상대적으로 어느 위치(고가 부근 또는 저가 부근)에 마감되었는지 측정합니다.
*   **수학적 공식:** 
    \\[\%K = \frac{Close_t - Low_n}{High_n - Low_n} \times 100\\]
    \\[\%D = SMA(\%K, m)\\]
*   **프로그래밍 매수 조건 (과매도 영역 내 골든 크로스):**
    ```python
    # %K선이 %D선을 20 이하(과매도 구간)에서 상향 교차할 때
    df['buy_signal'] = (df['percent_k'].shift(1) <= df['percent_d'].shift(1)) & \
                       (df['percent_k'] > df['percent_d']) & \
                       (df['percent_k'] <= 20)
    ```

#### 샨드 모멘텀 오실레이터 (Chande Momentum Oscillator, CMO)
*   **정의:** RSI 수식의 분모에 단순 차이가 아닌 모든 가격 변동의 절대 총합을 사용하여 가격 변화에 한층 더 직접적이고 민감하게 반응하는 오실레이터입니다.
*   **수학적 공식:** 
    \\[CMO = 100 \times \frac{S_u - S_d}{S_u + S_d}\\]
    *(\\(S_u\\): \\(n\\)일간 상승폭의 합, \\(S_d\\): \\(n\\)일간 하락폭의 합)*
*   **프로그래밍 매수 조건 (10일 SMA 상향 돌파):**
    ```python
    df['CMO_SMA'] = df['CMO'].rolling(window=10).mean()

    # CMO가 자신의 10일 단순이동평균을 돌파하고 상승 탄력을 받을 때
    df['buy_signal'] = (df['CMO'].shift(1) <= df['CMO_SMA'].shift(1)) & (df['CMO'] > df['CMO_SMA'])
    ```

#### 윌리엄스 %R (Williams %R)
*   **정의:** 최고가와 현재 종가 간의 이격을 측정하여 역값(0 ~ -100)으로 표시하며, 단기 바닥 구간을 민감하게 포착하는 과매도 지표입니다.
*   **수학적 공식:** 
    \\[\%R = \frac{High_n - Close_t}{High_n - Low_n} \times -100\\]
*   **프로그래밍 매수 조건 (과매도 탈출):**
    ```python
    # -80선(과매도 침체선) 이하에서 가격이 회복되며 상향 돌파할 때
    df['buy_signal'] = (df['williams_r'].shift(1) <= -80) & (df['williams_r'] > -80)
    ```

#### CCI (Commodity Channel Index)
*   **정의:** 가격의 당일 중간값(Typical Price)과 그 이동평균선의 통계적 편차를 측정하여 가격의 주기적 과열/침체를 계측합니다.
*   **수학적 공식:** 
    \\[TP = \frac{High + Low + Close}{3}, \quad CCI = \frac{TP - SMA(TP, n)}{0.015 \times MD(TP, n)}\\]
    *(\\(MD\\): 평균편차)*
*   **프로그래밍 매수 조건 (침체선 돌파 및 0선 도달):**
    ```python
    # 과매도 기준선인 -100선을 딛고 올라서는 시점
    df['buy_signal'] = (df['CCI'].shift(1) <= -100) & (df['CCI'] > -100)
    ```

#### 어썸 오실레이터 (Awesome Oscillator, AO)
*   **정의:** 5일 및 34일 중간값(Median Price) 단순이동평균의 차이를 통해 모멘텀의 가속도 방향과 반전 시점을 막대그래프로 나타냅니다.
*   **수학적 공식:** 
    \\[Median\_Price = \frac{High + Low}{2}\\]
    \\[AO = SMA(Median\_Price, 5) - SMA(Median\_Price, 34)\\]
*   **프로그래밍 매수 조건 (0선 돌파):**
    ```python
    # 오실레이터 막대가 음수 영역에서 양수 영역으로 전환될 때 (제로 라인 크로스)
    df['buy_signal'] = (df['AO'].shift(1) <= 0) & (df['AO'] > 0)
    ```

#### TSI (True Strength Index)
*   **정의:** 가격 변동량을 이중으로 지수 평활화하여 가격의 무작위 노이즈를 완벽하게 제거하고 순수한 모멘텀 방향을 부드러운 오실레이터로 계측합니다.
*   **수학적 공식:** 
    \\[Double\_Smoothed\_PC = EMA(EMA(PC, r), s)\\]
    \\[Double\_Smoothed\_AbsPC = EMA(EMA(|PC|, r), s)\\]
    \\[TSI = 100 \times \frac{Double\_Smoothed\_PC}{Double\_Smoothed\_AbsPC}\\]
    *(PC: 가격 변동량 \\(Close_t - Close_{t-1}\\), r=25, s=13)*
*   **프로그래밍 매수 조건 (0선 상향 교차):**
    ```python
    # TSI 선이 중심인 0선을 하단에서 상단으로 돌파할 때
    df['buy_signal'] = (df['TSI'].shift(1) <= 0) & (df['TSI'] > 0)
    ```

#### 보텍스 지표 (Vortex Indicator)
*   **정의:** 최근의 고점과 저점을 이전 기간과 비교하여 상승 소용돌이선(VI+)과 하락 소용돌이선(VI-)을 계산하고, 이들의 교차로 새로운 추세의 탄생을 알립니다.
*   **수학적 공식:** 
    \\[+VM = |High_t - Low_{t-1}|, \quad -VM = |Low_t - High_{t-1}|\\]
    \\[VI+ = \frac{\sum +VM}{\sum TR}, \quad VI- = \frac{\sum -VM}{\sum TR}\\]
*   **프로그래밍 매수 조건 (두 지표선의 골든 크로스):**
    ```python
    # VI+선이 VI-선을 상향 돌파할 때 (매수 에너지 증가)
    df['buy_signal'] = (df['VI_plus'].shift(1) <= df['VI_minus'].shift(1)) & (df['VI_plus'] > df['VI_minus'])
    ```

#### 내부 바 강도 (Internal Bar Strength, IBS)
*   **정의:** 당일 가격의 총 변동 범위(고가-저가) 대비 종가의 상대적 마감 위치를 계산하여 극단적 과매도 상태의 즉각적인 평균 회귀 반등을 노립니다.
*   **수학적 공식:** 
    \\[IBS = \frac{Close - Low}{High - Low}\\]
*   **프로그래밍 매수 조건 (극단적 과매도):**
    ```python
    # IBS 수치가 0.1 이하로 종가가 당일 변동폭의 최저점에 마감하는 극 침체 국면 발생 시
    df['buy_signal'] = df['IBS'] <= 0.1
    ```

### 3. 변동성 및 돌파 지표 (Volatility Indicators)

#### 볼린저 밴드 (Bollinger Bands)
*   **정의:** 가격의 단순이동평균선을 중심으로 통계적 표준편차를 가감하여 신뢰 수준 95% 내외의 가변 가격 채널 범위를 작도합니다.
*   **수학적 공식:** 
    \\[Middle\_Band = SMA_{20}(Close)\\]
    \\[Upper\_Band = Middle\_Band + (2 \times StdDev)\\]
    \\[Lower\_Band = Middle\_Band - (2 \times StdDev)\\]
*   **프로그래밍 매수 조건 (스퀴즈 후 상단 밴드 돌파):**
    ```python
    df['bandwidth'] = (Upper_Band - Lower_Band) / Middle_Band

    # 1. 변동성이 극도로 수축했는지 확인 (최근 20일 기준 밴드폭 최저 도달)
    is_squeezed = df['bandwidth'] == df['bandwidth'].rolling(window=20).min()

    # 2. 수축 상태에서 상단 밴드를 강하게 돌파하는 상승 변동성 분출 발생 시
    df['buy_signal'] = is_squeezed & (df['close'].shift(1) <= Upper_Band.shift(1)) & (df['close'] > Upper_Band)
    ```

#### TTM Squeeze
*   **정의:** 볼린저 밴드가 상대적으로 안정적인 변동성 채널인 켈트너 채널 내부로 수축(응축)되었다가, 외부로 다시 튕겨 나가는 분출 매커니즘을 시각화합니다.
*   **수학적 공식:** 볼린저 밴드 상단이 켈트너 채널 상단 내부로 들어오고, 하단이 켈트너 하단 내부로 수렴하면 Squeeze ON(빨간 점) 상태 유지. 이후 외부로 확장되면 Squeeze Fired(초록 점).
*   **프로그래밍 매수 조건 (Squeeze Fired + Positive Momentum):**
    ```python
    # 이전 봉에서는 Squeeze가 활성화 상태(빨간 점)였으나,
    squeeze_on_prev = (BB_Upper.shift(1) < KC_Upper.shift(1)) & (BB_Lower.shift(1) > KC_Lower.shift(1))
    # 현재 봉에서 Squeeze가 분출(초록 점)되고 모멘텀 오실레이터가 양수인 경우
    squeeze_fired_now = (BB_Upper >= KC_Upper) | (BB_Lower <= KC_Lower)
    momentum_positive = df['momentum_hist'] > 0

    df['buy_signal'] = squeeze_on_prev & squeeze_fired_now & momentum_positive
    ```

#### 돈천 채널 (Donchian Channels)
*   **정의:** 특정 기간(n) 내 최고가와 최저가 선을 작도하여 채널 범위를 만들고, 이 범위를 넘어서는 신고가 발생 시 강력한 모멘텀 돌파로 간주합니다.
*   **수학적 공식:** 
    \\[Upper\_Channel = Max(High, n)\\]
    \\[Lower\_Channel = Min(Low, n)\\]
*   **프로그래밍 매수 조건 (신고가 상향 돌파):**
    ```python
    # 가격이 이전 20일간의 최고가를 뚫고 신기록을 경신하며 강세를 보일 때
    df['upper_band'] = df['high'].shift(1).rolling(window=20).max()
    df['buy_signal'] = df['close'] > df['upper_band']
    ```

### 4. 거래량 및 수급 지표 (Volume Indicators)

#### 차이킨 머니 플로우 (Chaikin Money Flow, CMF)
*   **정의:** 장 중 주가의 마감 위치(종가)와 당일의 거래량을 연계 가중하여 시장에 실질적으로 자금이 유입(매집)되는지 혹은 이탈(분산)되는지 측정합니다.
*   **수학적 공식:** 
    \\[MF\_Multiplier_t = \frac{(Close_t - Low_t) - (High_t - Close_t)}{High_t - Low_t}\\]
    \\[MF\_Volume_t = MF\_Multiplier_t \times Volume_t\\]
    \\[CMF = \frac{\sum_{i=0}^{n-1} MF\_Volume_{t-i}}{\sum_{i=0}^{n-1} Volume_{t-i}}\\]
*   **프로그래밍 매수 조건 (0선 상향 돌파):**
    ```python
    # CMF 수치가 0선 위인 양수의 영역으로 돌파하여 시장에 '순매수 수급'이 발생할 때
    df['buy_signal'] = (df['CMF'].shift(1) <= 0) & (df['CMF'] > 0)
    ```

#### OBV (On-Balance Volume)
*   **정의:** 주가의 상승 및 하락 방향에 맞춰 거래량을 단순 누적 합산하여 가격 변화에 선행하는 시장 거래 대금의 축적을 분석합니다.
*   **수학적 공식:** 
    \\[OBV_t = OBV_{t-1} + \begin{cases} Volume_t & \text{if } Close_t > Close_{t-1} \\ 0 & \text{if } Close_t = Close_{t-1} \\ -Volume_t & \text{if } Close_t < Close_{t-1} \end{cases}\\]
*   **프로그래밍 매수 조건 (OBV 고점 선행 돌파):**
    ```python
    # 가격은 직전 고점을 뚫지 못했으나, OBV 수치가 먼저 직전 최고 OBV를 돌파하여 매집이 감지될 때
    df['obv_peak'] = df['OBV'].shift(1).rolling(window=20).max()
    df['buy_signal'] = df['OBV'] > df['obv_peak']
    ```

#### CVD (Cumulative Volume Delta)
*   **정의:** 시장가로 직접 즉각 결제하는 공격적인 시장가 매수 주문과 매도 주문의 거래량 누적 델타값을 측정해 실시간 세력 침투를 포착합니다.
*   **수학적 공식:** 
    \\[CVD = \sum (Market\_Buy\_Volume - Market\_Sell\_Volume)\\]
*   **프로그래밍 매수 조건 (강세 다이버전스):**
    ```python
    # 가격 저점은 직전 저점보다 낮아졌으나(하락), CVD 수치의 저점은 오히려 높아질 때(시장가 매집 포착)
    price_low_falling = df['low'] < df['low'].shift(1)
    cvd_low_rising = df['CVD'] > df['CVD'].shift(1)

    df['buy_signal'] = price_low_falling & cvd_low_rising
    ```

#### Williams VixFix (합성 VIX 지수)
*   **정의:** 22일 최고 종가 대비 현재 저가의 이격 수준을 역발상으로 환산하여, 변동성 지수(VIX)가 없는 개별 자산에서도 패닉 바닥 영역을 유도해내는 지표입니다.
*   **수학적 공식:** 
    \\[VixFix = \frac{Max(Close, 22) - Low_t}{Max(Close, 22)} \times 100\\]
*   **프로그래밍 매수 조건 (패닉 오버슈팅 후 꺾임):**
    ```python
    # VixFix 수치가 과거 극대화 수치(예: 22일 기준 최고치)에 도달하며 공포의 바닥을 찍고 내려올 때
    vix_peak = df['VixFix'].rolling(window=22).max()
    df['buy_signal'] = (df['VixFix'].shift(1) >= vix_peak.shift(1) * 0.9) & (df['VixFix'] < df['VixFix'].shift(1))
    ```

### 5. 정밀 카운팅 및 복합 트레이딩 시스템

#### TD Sequential (DeMark Sequential)
*   **정의:** 종가와 4봉 전 종가의 대소 관계를 연속 카운팅하여 셋업(Setup)과 카운트다운(Countdown) 단계를 거쳐 추세 소진점을 완벽하게 잡아냅니다.
*   **수학적 공식 및 규칙:**
    *   **TD Buy Setup 9:** 종가가 4봉 전 종가보다 낮은 마감이 9봉 연속 유지될 때 완성.
    *   **Countdown 13:** Setup이 완료된 캔들 이후, 종가가 2봉 전의 종가보다 낮은 날이 누적 13회 완성되는 시점.
*   **프로그래밍 매수 조건:**
    ```python
    # 1. 9-Setup 완료 판정
    setup_ok = True
    for i in range(9):
        if df['close'].shift(i) >= df['close'].shift(i+4):
            setup_ok = False

    # 2. Setup_OK가 참인 상태에서 누적 카운트다운 13에 도달할 때 진입
    if setup_ok and (accumulated_countdown == 13):
        buy_signal = True
    ```

#### 알렉산더 엘더 삼중 스크린 시스템 (Alexander Elder's Triple Screen)
*   **정의:** 단일 지표의 상충 신호를 거르기 위해 세 프레임의 추세를 순차 다중 필터링하여 장기 상승 조수 속에서 단기 하락 풀백을 잡아 진입합니다.
*   **정량적 공식:**
    *   **제1스크린 (장기):** \\(Close_t > Close_{t-250}\\) (장기 이평 필터 우상향)
    *   **제2스크린 (중기):** \\(Close_t > Close_{t-22}\\) (중기 기준선 우상향)
    *   **제3스크린 (단기 풀백):** \\(Close_t == Min(Close_t, Close_{t-1}, Close_{t-2})\\) (단기 3일 최저점 진입)
*   **프로그래밍 매수 조건 및 청산:**
    ```python
    # 3중 조건이 완벽히 합치되는 교차점에서 종가 매수 진입
    long_term = df['close'] > df['close'].shift(250)
    intermediate = df['close'] > df['close'].shift(22)
    short_pullback = df['close'] == df['close'].rolling(window=3).min()

    df['buy_signal'] = long_term & intermediate & short_pullback

    # 청산 조건: 다음날 종가가 어제 종가보다 높을 때 즉시 전량 청산
    df['exit_signal'] = df['close'] > df['close'].shift(1)
    ```
