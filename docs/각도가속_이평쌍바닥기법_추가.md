# 각도 가속·이평선 쌍바닥 기법

최소제곱 선형회귀 기반 각도 가속 신호와 이동평균선 쌍바닥 패턴을 결합한 단기 매매 전략.
상승 추세의 가속도가 확인되는 구간에서 쌍바닥 패턴의 넥라인 돌파 시점에 진입한다.

> 이 문서는 향후 PRD 작성 및 "또는(OR)" 다중 후보 전략 결합 검색을 위한 기초 자료이다.
> 각 후보 조합은 별도로 기술하며, 공통 진입 조건은 하단의 "공통 구조"를 우선한다.

---

## 1. 공통 구조 (Core Concept)

### 진입 조건 (모두 동시 충족 — AND)
1. **각도 가속**: 로그가격의 `slope_window`봉 최소제곱 선형회귀 기울기가 `accel_window`봉 전 대비
   `min_slope_delta` 이상 증가 (상승 각도가 가파라지는 구간)
2. **이평선 쌍바닥**: 이평선(`ma_window`)이 쌍바닥(국소 저점 2개, 둘 다 같은 수준 또는 높은 저점)을
   형성 후 넥라인(두 저점 사이 반등 고점)을 상향 돌파

### 청산 조건
- **익절(TP)**: +3% (고정)
- **손절(SL)**: -4% (고정)
- **tp_first**: True (같은 봉 TP·SL 동시 도달 시 익절 우선)
- **최대 보유**: 없음 (기본값)
- **비용**: 편도 0.0005 (왕복 0.1%)

## 2. 핵심 후보 조합 (OR 검색용)

### 표본 확대형
| 항목 | 값 |
|------|-----|
| 회귀 윈도우 (`slope_window`) | 30 |
| 가속 비교 기간 (`accel_window`) | 5 |
| 최소 가속량 (`min_slope_delta`) | 0.0045 |
| 이평선 기간 (`ma_window`) | 16 |
| 익절 (TP) | 3% |
| 손절 (SL) | 4% |
| **승률** | **73.1%** |
| **PF** | **1.92** |
| 평균 수익 | +1.015% |
| 총 거래 | 182건 |
| **월간 거래건수** | **2.8건** |

- 특징: 후보 A보다 가속 필터를 약간 강화(0.0045). 승률과 표본의 균형이 후보 A와 비슷하나
  약간 더 높은 수익률.
