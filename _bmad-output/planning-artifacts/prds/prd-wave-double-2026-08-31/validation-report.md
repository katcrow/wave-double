Fix (BLOCKING): FR-8에 "진입일로부터 N거래일(초기값 20) 미도달 시 `TIMEOUT` 확정 + N거래일째 종가 손익률 기록, 이후 조회 대상 제외" 추가. Consequence: `P ≤ (일평균 태깅 후보 수 × N)`. FR-9에 "종결 건만 분모, `종결 n / 진행중 m` 병기, 종결 30건 미만이면 '표본 부족(n=k)'". OQ-2 삭제. **N은 임의값이 아니라 C3에서 확인한 백테스트 실제 N과 같아야 한다.**
