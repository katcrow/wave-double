## 시작과 미확정 항목

- 첫 작업은 1.1 배포·CI·스키마 기준과 기존 정상 배치 한 건의 전체 경로 확인이다.
- 4.1 현금 초과 진입은 수정 전 재현·상세 완료 조건 정리가 필요하며 refine=true다. 실행 재현 전 코드 근거만으로 운영 장애라고 주장하지 않는다.
- 4.3은 초기자본·종목비중·동시보유 한도 확정 전 unknown으로 차단한다. 이 조건은 트리 승인 후 측정 실행 전에 정해도 된다.
- 1.2가 운영 실행과 검증창을 소유하며 2.3이 그 증거·창을 소비한다. 같은 운영 배치를 검증 목적으로 동시에 자극하지 않는다.
- 모든 항목은 planned이며 실제 제품 검증·구현·배포를 시작하지 않았다. 승인 전 refined=false인 에픽 아래의 상세 항목도 검토용 초안이다.
- 2.2와 2.3은 별도 브라우저 컨텍스트의 읽기 검증으로 진행한다. 공유 mock 시나리오나 테스트 파일을 수정해야 하면 하나의 작업이 소유하도록 실행 계획에서 직렬화한다.

## 승인 절차

사용자가 제안한 분할·순서·위험도를 승인하면 초안 표기를 확정하고 이 작업으로 작성한 티켓 파일만 현재 브랜치에 커밋한다. 기존 사용자 변경 두 파일은 포함하지 않는다. 커밋은 push·배포 또는 개별 티켓 실행을 뜻하지 않는다.
