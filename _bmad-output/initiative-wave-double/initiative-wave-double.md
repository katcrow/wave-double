# 개인투자자를 위한 매수후보 추천 대시보드

## Description

개인투자자 Neo가 매 거래일 매수후보와 근거를 한 화면에서 확인하도록 웹 대시보드(`apps/web/`), Python 배치(`apps/batch/`), 백테스트 커널(`backtest/`)을 운영한다. MVP와 v6 기간의 작업은 모두 완료·배포되었고, 이후 작업은 이 이니셔티브 아래 새 티켓으로 시작한다.

## Outcome

Neo가 장 마감 전후 대시보드만으로 매수후보를 판단할 수 있다.
