## Intent

**Problem:** 태깅된 후보의 근거 패널(Epic 4 후속 스토리)에 표시할 D-2/D-1/D0 3일치 가격·수급 데이터가 아직 수집되지 않는다. `supply_3day` 스키마(Story 2.6)는 존재하지만 값을 채우는 batch stage가 없다.

**Approach:** candidates/tags stage 뒤에 새 `supply_3day` stage를 배선해, 태깅된(`candidate_tags.status='active'`) 각 후보에 대해 LS `t1702`를 후보당 1콜(fromdt=D-2 거래일, todt=D0) 호출하고, `trading_calendar` 기준 정확한 3거래일에 매핑해 `supply_3day`에 저장한다. 이 stage 성공을 `publish_attempt`/`get_dashboard_snapshot()`의 계약에 반영한다.

## Boundaries & Constraints

**Always:** 후보당 t1702 1콜만(Story 1.4 `LsClient`를 통해서만 호출, NFR-3 1건/초 예산 준수). D-2/D-1/D0은 `trading_calendar`(`is_open=true`)에서 조회한 거래일 기준으로 산출하며 달력일로 근사하지 않는다(연휴 직후도 정확해야 함). t1702의 `diff` 필드를 그대로 `change_pct`로 저장한다(재계산 금지 — LS가 이미 전일 종가 대비 값을 제공). 한 종목의 실패(비-ok 응답, 예상 3거래일 중 누락된 날짜)가 나머지 후보 처리를 막지 않고 error로 집계한다(`tags_stage.py` 패턴). stage 성공 시에만 `stage_status.supply_3day='success'`를 기록하고, `publish_attempt`는 이 stage가 success여야만 진행한다. batch_kind(close/intraday) 관계없이 tags stage 직후 실행한다(Story 4.3의 장중 D0 누적 전제).

**Never:** `program_net` 채우기(t1637, Story 4.2 범위 — NULL로 둔다). 투자자별 필드 전부 0/미확정 구분 가드(Story 4.4 범위 — 이번 스토리는 응답이 있으면 `investor_net_status='confirmed'`로 단순 기록). `market_supply`/t1601(Story 4.5). `trading_calendar` 자체 신규 채움(Story 1.2에서 이미 존재, 조회만 한다).

**Acceptance Criteria:**
- Given 태깅된 후보 목록과 정상 t1702 응답, when supply stage가 실행되면, then 후보당 1콜로 D-2/D-1/D0 3행이 `supply_3day`에 저장되고 `stage_status.supply_3day='success'`가 기록된다.
- Given `stage_status.supply_3day`가 success가 아닌 attempt, when `publish_attempt`가 호출되면, then `SUPPLY_3DAY_STAGE_NOT_COMPLETE` 예외로 실패하고 발행되지 않는다.
- Given supply stage가 success로 완료된 attempt, when `get_dashboard_snapshot()`을 호출하면, then `supply_3day`가 `missing_sections`에서 빠지고 해당 section이 반영된다.
- Given 태깅된 후보가 없는 attempt, when supply stage가 실행되면, then 0행 처리로 success 기록(에러 아님).

## Design Notes

t1702 요청은 `volvalgb="1"`(수량, Story 4.2의 t1637 `svolume` 수량 기준과 일관), `msmdgb="0"`(순매수), `gubun="0"`(일간, 누적 아님), `exchgubun="U"`(통합)로 고정한다. 응답은 최신일이 먼저 오지만(`foreign-institution.md:117-141` 예시), 순서에 의존하지 말고 각 행의 `date`를 D-2/D-1/D0 날짜와 문자열 비교(`YYYYMMDD`)로 매핑한다.
