# 데이터·모델·운영 계약

## 성공 라벨

기준일 `d`의 코스피 종합(LS 업종코드 `001`)과 코스닥 종합(`301`)에 대해 각 시장별로 계산한다.

`label(d) = 1 if high(next_joint_trading_day(d)) > close(d), else 0`

같은 가격은 실패다. 주말·휴일에는 다음 공동 거래일을 사용한다. 기준일 종가가 없거나 다음 거래일 고가가 아직 확정되지 않은 표본은 학습·평가에서 제외한다.

## 실행·결과 계약

- KST 매일 15:00, 15:20, 15:40, 16:00, 16:20, 16:40, 17:00, 17:20, 17:40, 18:00, 18:20, 18:40, 19:00에 실행한다.
- 기존 `premarket`/`intraday`/`close` 후보 추천 실행은 재사용하지 않는다. 별도 확률 작업으로 후보 수집·태깅·주문 영향 없이 계산한다.
- 결과 자연키는 `trading_day`다. 한 행에 `target_trading_day`, `kospi_probability`, `kosdaq_probability`, `last_success_at`, `feature_as_of`, `model_version`, `validation_status`, `input_quality`, 입력 snapshot을 둔다.
- 성공한 계산에서만 기존 행을 upsert한다. 실패하면 이전 행을 바꾸지 않는다. 동시 실행·재시도는 거래일 키와 실행시각 순서 검증으로 오래된 계산이 최신 결과를 덮지 않게 한다.
- 각 성공 실행은 해당 거래일의 최신 확률을 덮어쓴다. 장 마감 후 별도 실행은 없다.

## 데이터 후보와 현재 증거

| 신호 | TR | 활용 후보 | 확인된 한계 |
|---|---|---|---|
| 종합지수, 상승·보합·하락 종목 수 | `t1511` | 양 시장 등락률, breadth | 조회 가능; 응답에 일관된 원천 관측시각 없음 |
| 시장 투자자별 순매수 | `t1601` | 외국인·기관·개인 수급 | 장중 조회 가능; 수집시각 저장 필요 |
| 프로그램 매매 | `t1631` | 차익·비차익·전체 수급 | 장중 조회 가능; 수집시각 저장 필요 |
| 나스닥100 선물·원달러 | `t3521` | 해외 위험선호·환율 변화 | 조회 가능; quote date가 시간시각을 대신하지 않음 |
| KOSPI200·KOSDAQ150 선물 | `t8467` + `t2111` | 선물 등락·베이시스·미결제약정 | 마스터·현재가 조회 가능; 원천 체결시각이 없음 |
| 해외선물 분봉 | `t3518` | 시점별 NQ 등락 | 30분 조회에서 빈 행 응답 확인; 사용 금지 |

현재 TR 조회 성공은 15:00~19:00 시세 신선도의 증거가 아니다. 실제 예정시간 관측에서 반복해서 값이 변하는지 확인하고, 가능하면 거래일/시각 필드와 거래 상태를 검사한다. 원천시각이 없는 값에는 `collected_at`만 신뢰 가능한 시각으로 기록한다.

### 이력 길이 및 탐색 실험

- LS `t8429` 코스피·코스닥 일봉과 `t8466` 지수선물 일봉은 2024-09-27~2026-10-20에 각각 499개를 날짜 정합했다. 현 선물코드로 2019~2020 조회는 비어 있었다.
- 2026년 193개 외부표본에서 지수 일봉 모델에 지수선물 일봉수익률을 더한 탐색 로지스틱은 코스피 Brier `0.1672 → 0.1659`(상위 예측 20% 성공률 동일 `81.6%`), 코스닥 Brier `0.1460 → 0.1532`(상위 20% `73.7% → 78.9%`, 하위 20% `84.2% → 92.1%`)였다. 선물 일봉의 일관된 개선은 확인하지 못했다.
- 이 제한된 일봉 실험은 장중 15:00~19:00 선물 신호를 시험하지 않았다. 선물 일봉 결과만으로 장중 선물을 제외하지 않는다.

## 모델·검증 규칙

1. 코스피와 코스닥을 따로 모델링한다. 우선 확정 종가 기반 지수 일봉을 기준 모델로 두고, 장중 입력은 현재 시각에서 실제 이용 가능했던 값으로 재현할 수 있을 때 challenger 변수로 평가한다.
2. 확률은 확장형 시간순 검증으로 산출한다. 각 검증일의 모델은 그 날짜 전까지의 라벨과 특성만 학습한다. 무작위 train/test 분할, 미래 시점 값으로 과거 결측 보정, 전체 표본 기준 정규화는 금지한다.
3. 단순 상승률/학습 구간 비율 기준 모델과 Brier 점수·로그손실을 비교한다. 신뢰도 구간별 예측확률과 실제 성공률, 고확률 구간의 전체 대비 성공률도 시장별로 기록한다.
4. 검증 기준모델보다 보정 성능이 나쁘거나 고확률 그룹의 실현률 우위가 확인되지 않으면 `validation_status=experimental`로 둔다. 화면은 검증 중 표시를 유지하고 우위가 있다고 표현하지 않는다.
5. 새 장중 자료로만 얻는 신호는 충분한 시계열을 쌓기 전까지 검증된 모델에 섞지 않는다. 기준 모델과 challenger 결과, 표본 수, 기간, 데이터 결측률을 분리 기록한다.
